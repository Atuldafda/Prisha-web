# Clay & Co. | Artisan Pottery Studio

## Project Overview
Clay & Co. is a contemporary digital experience designed for a local artisan pottery studio. The goal was to create a web presence that reflects the tactile, handcrafted nature of ceramics while providing a modern, high-performance user experience.

## Key Features
- **Artisanal Branding:** Custom color palette (Clay & Stone tones) and typography (serif/sans-serif mix) to match the studio's aesthetic.
- **Dynamic Hero Section:** Smooth animations using Framer Motion to create an inviting entrance.
- **Curated Gallery:** A responsive showcase of handcrafted pieces with interactive hover states.
- **Studio Workshops:** A clear, structured section for booking wheel-throwing and hand-building classes.
- **Integrated Contact:** A polished studio visit/inquiry section to drive local engagement.

## Technical Stack
- **Frontend:** React with TypeScript
- **Styling:** Tailwind CSS (customized brand configuration)
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Build Tool:** Vite

## Agency Context
This project serves as a showcase piece for **Prisha Web**. It demonstrates our ability to build niche-specific, brand-aware landing pages for small businesses and artisans.
